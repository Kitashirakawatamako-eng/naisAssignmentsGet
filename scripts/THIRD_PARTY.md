# 第三方组件

安装使用 Astral 发布的 Python 3.13.18。运行包附带的 CPython 和其他组件许可位于应用内的 Python 目录。CTranslate2、NumPy、PyYAML、SentencePiece 和 certifi 的许可位于各自的 Python 包内。 [Python Build Standalone 20261110](https://github.com/astral-sh/python-build-standalone/releases/tag/20261110)

英译中模型来自 [Argos Translate 的模型索引](https://github.com/argosopentech/argospm-index)，采用 [OPUS-MT](https://aclanthology.org/2020.eamt-1.61/) 的英语至中文模型，作者为 Jörg Tiedemann 和 Santhosh Thottingal。模型的 Argos 打包版本为 1.9，原模型采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。随包保留了模型原有的说明和元数据。
