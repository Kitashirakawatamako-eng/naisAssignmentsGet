# Third-Party Components

The installer bundles Python 3.13.18 published by Astral. Licenses for CPython and its components are in the app's Python directory. Licenses for CTranslate2, NumPy, PyYAML, SentencePiece, and certifi are included with their respective Python packages. [Python Build Standalone 20261110](https://github.com/astral-sh/python-build-standalone/releases/tag/20261110)

The Chinese-to-English model comes from the [Argos Translate package index](https://github.com/argosopentech/argospm-index). It uses the Chinese-to-English [OPUS-MT](https://aclanthology.org/2020.eamt-1.61/) model by Jörg Tiedemann and Santhosh Thottingal. The Argos package version is 1.9, and the original model is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The model's original notes and metadata are included in the app.
